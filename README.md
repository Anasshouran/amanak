# AMANAK | الأمانك

Defensive personal cybersecurity application.

## Overview

AMANAK is a defensive cybersecurity application designed to protect your digital life. It provides:

- **Mobile app** (React Native + Expo): On-device security scanning and monitoring
- **Web app** (React + Vite): Dashboard and analytics
- **Backend** (Django + DRF): Core logic, API, and data storage
- **Security engine**: Rule-based threat detection and analysis
- **AI gateway**: Provider-agnostic AI integration (disabled by default)

## Architecture

This is a monorepo structure with clearly separated packages and applications. See `docs/architecture/initial-architecture.md` for detailed architecture documentation.
