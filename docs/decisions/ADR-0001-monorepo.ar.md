# ADR-0001: المستودع الواحد (Monorepo)

- الحالة: معتمد
- التاريخ: P0

## السياق

يضم أمانك تطبيق جوال، تطبيق ويب، خادم خلفي، محرك أمان، بوابة AI، حزماً مشتركة، بنية تحتية، واختبارات. تتشارك هذه المكونات العقود ومتطلبات الأمان.

## القرار

استخدام مستودع واحد (Monorepo) بمجلدات رئيسية مفصولة بوضوح.

## التبعات

- الأنواع المشتركة وعميل API أسهل في المزامنة.
- يتطلب قواعد ملكية وفروعاً/مساحات عمل معزولة للوكلاء المتوازيين.
- يجب أن يدعم CI/CD عمليات البناء على مستوى المسارات.
