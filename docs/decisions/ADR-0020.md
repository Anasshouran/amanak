# ADR-0020 — Hybrid AI: Cloud (Anthropic/Groq) + Local (Ollama)

Status: **Accepted with conditions** (P20.4).

## Context
P3 (AI Assistant) used only local Ollama (`AI_ENABLED=false` by default). The user needs cloud capabilities (Anthropic `claude-3-5-haiku`, optional Groq) for production use while preserving privacy.

## Decision
Break the "local only" posture. Introduce cloud providers with:

- **Aggressive redaction** (`security-engine/redaction_cloud.py`): URLs (host + query), emails, phones, secrets masked before transmission.
- **Consent gate**: `AI_CLOUD_CONSENT=true` required for any cloud provider (`openai`, `anthropic`, `groq`).
- **Local unchanged**: Ollama uses the light `redaction_cloud` — no quality loss.
- **Rate limits**: 100/day/user (`AI_DAILY_LIMIT`), 1000/day global.
- **Privacy model B**: URLs fully redacted (primary phishing evidence carrier).
- **Payment model**: admin puts `ANTHROPIC_API_KEY` / `GROQ_API_KEY` in env; product pays (not user-paywalled).

## Consequences
- Positive: Production-grade AI with privacy floor.
- Negative: Data leaves the system (redacted) for cloud inference. Must be documented in `.env.example` and privacy page.
- Technical debt: E2E tests skipped (mock contract mismatch); manual verification required.
