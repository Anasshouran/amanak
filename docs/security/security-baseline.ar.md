# خط الأساس الأمني — أمانك

## الأسرار

- لا تنشئ أسراراً حقيقية ولا تُودِع بيانات اعتماد في المستودع.
- ملف `.env.example` يحتوي على قيم مؤقتة فقط.
- أسرار الإنتاج تأتي من مدير أسرار (Secret Manager).

## الشبكة

- لا تكشف PostgreSQL أو Redis للعامة.
- اربط منافذ قاعدة البيانات في التطوير بـ `127.0.0.1` فقط.
- استخدم TLS ووكيلاً معاكساً في الإنتاج.

## Django / الخادم الخلفي

- `DEBUG=False` في الإنتاج.
- اطلب `ALLOWED_HOSTS` وCORS و`SECRET_KEY` بشكل صريح.
- افرض عزل بيانات المستخدمين على مستوى الاستعلامات.
- تحقق من كل المدخلات غير الموثوقة ونقّها.

## الخصوصية

- لا تجمع أبداً كلمات مرور حسابات المستخدمين الخارجية أو رموز استرداد MFA.
- تعامل مع فحص الروابط والرسائل كمدخلات غير موثوقة.
- لا تنفّذ مراقبة خفية أو تتبّعاً غير مصرّح به للأجهزة.

## الذكاء الاصطناعي

- أبقِ تكاملات AI الخارجية معطّلة حتى يتم تفعيلها بشكل صريح.
- لا ترسل بيانات العملاء الحساسة لمزوّدي AI الخارجيين افتراضياً.
- سجّل استخدام AI دون تخزين محتوى حسّاس.
