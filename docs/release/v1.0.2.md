## What's New vs v1.0.1

v1.0.2 = v1.0.1 + P20.5 (OpenRouter cloud AI provider).

### Added
- **OpenRouter** as third cloud AI provider (alongside Anthropic and Groq)
  - OpenAI-compatible API
  - Access to hundreds of models via single endpoint
  - Per-request privacy routing:
    - `data_collection: "deny"` — exclude providers that may train
    - `zdr: true` — Zero Data Retention only
    - `allow_fallbacks: true` — automatic fallback
  - Redaction applied before send (same as Anthropic/Groq)

### Fixed
- **6 previously failing Cloud AI tests** (from P20.4)
  - Router consent tests
  - Rate limit tests
  - Redaction mock
  - Status endpoint shape
  - All 37 AI tests now pass (was 31/37)

## AI Providers

| Provider | Type | Privacy | Cost |
|----------|------|---------|------|
| **Ollama** | Local | 100% (no transmission) | Free |
| **Anthropic** | Cloud | redacted, no-training | ~$0.0003/call |
| **Groq** | Cloud | redacted | Free (limited) |
| **OpenRouter** | Cloud | redacted, ZDR only | Varies by model |

**Default**: Ollama (AI_ENABLED=false + AI_PROVIDER unset = no AI).

**Cloud activation**: requires `AI_CLOUD_CONSENT=true` + `AI_CLOUD_API_KEY`.
