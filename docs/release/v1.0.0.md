## Lessons Learned

1. **990 tests don't replace 1 real user.** Many bugs (kdf_salt, wrapKey, src/app/) were invisible to tests.
2. **Local exercise > CI.** 1 manual run found 4 bugs that 990 tests missed.
3. **Ports matter.** 5432 vs 5433, 6379 vs 6380 caused repeated failures. Documented now.
4. **Fail-fast > fail-silent.** `wrapKey` failed silently for months. Would have been caught by explicit test.
5. **Scope creep is real.** 35 phases, 0 users. Feature 15 won't change that.
6. **Commit > describe.** Multiple times "test passes" was claimed without literal proof.
