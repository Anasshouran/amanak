# المعمارية الأولية — أمانك

## نظرة عامة

أمانك تطبيق دفاعي للأمن السيبراني الشخصي. يصف هذا المستند المعمارية المقترحة لحدود الخدمات في المرحلة P0.

## القرارات التقنية

- الجوال: React Native + Expo + TypeScript + Expo Router
- الويب: React + Vite + TypeScript
- الخادم الخلفي: Django + Django REST Framework
- قاعدة البيانات: PostgreSQL
- المهام الخلفية: Redis + Celery
- البنية التحتية: Docker Compose + Nginx
- الذكاء الاصطناعي: بوابة مستقلة عن المزوّد، معطّلة افتراضياً
- الاختبارات: pytest للخادم الخلفي؛ TypeScript للواجهات

## هيكل المستودع الواحد

- `apps/mobile` — تطبيق الجوال
- `apps/web` — تطبيق الويب
- `backend` — مشروع Django، التطبيقات، الأدوات المشتركة
- `security-engine` — القواعد، المحللات، السمعة
- `ai` — البوابة، الأوامر، قاعدة المعرفة، التقييمات
- `packages` — العقود المشتركة: عميل API، الأنواع، نظام التصميم
- `infrastructure` — Docker، Nginx، المراقبة، السكربتات
- `tests` — التكامل، من الطرف للطرف، الأمان
- `docs` — الوثائق: المعمارية، API، الأمان، العمليات، القرارات

## حدود الخدمات

- الجوال والويب يتواصلان فقط عبر API الخادم الخلفي.
- الخادم الخلفي يملك المصادقة، التصريح، وعزل بيانات المستخدمين.
- محرك الأمان يعالج الروابط والرسائل غير الموثوقة؛ يجب عزله وتحديد معدل طلباته.
- بوابة الذكاء الاصطناعي اختيارية ومعطّلة افتراضياً. لا تخرج أي بيانات حساسة من النظام بدون تهيئة صريحة.
- PostgreSQL و Redis خدمات خاصة؛ لا يتم كشفها للعامة أبداً.

## تدفق البيانات

1. العميل يرسل طلباً إلى API الخادم الخلفي.
2. الخادم يتحقق من المدخلات، يفرض عزل المستخدم، ويحفظ البيانات.
3. للفحص، يستدعي الخادم محرك الأمان.
4. لميزات AI، يستدعي الخادم بوابة AI فقط إن كانت مفعّلة.
5. المهام الخلفية تستخدم Redis + Celery.
