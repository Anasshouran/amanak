# ملكية الوكلاء — أمانك

| الوكيل | المسارات المملوكة | المسؤوليات |
|---|---|---|
| المعماري (Architect) | `docs/architecture`, `docs/decisions` | المعمارية، قرارات ADR، العقود المشتركة |
| وكيل الجوال | `apps/mobile` | تطبيق React Native + Expo |
| وكيل الويب | `apps/web` | تطبيق React + Vite |
| وكيل الخادم | `backend` | Django، DRF، عزل البيانات |
| وكيل الأمان | `tests/security`، مراجعة الأمان | اختبارات الأمان، مراجعة التهديدات |
| وكيل AI | `ai`، تكامل `security-engine` | بوابة AI، الأوامر، التقييمات |
| وكيل الجودة | `tests` | التكامل، من الطرف للطرف، بوابات الجودة |
| وكيل DevOps | `infrastructure`, CI/CD | Docker، Nginx، المراقبة، النشر |

## القواعد

- على الوكلاء استخدام فروع Git أو worktrees معزولة للعمل المتوازي.
- يجب الاتفاق على العقود المشتركة قبل بدء العمل المتوازي.
- التغييرات الحساسة أمنياً تتطلب مراجعة قبل الدمج.
- لا تودع أسراراً أو بيانات اعتماد حقيقية.
- لا تفعّل تكاملات AI الخارجية افتراضياً.
