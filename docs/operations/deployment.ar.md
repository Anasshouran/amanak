# النشر — أمانك

## متطلبات الإنتاج

- `DEBUG=False`
- `SECRET_KEY` من مدير أسرار
- `ALLOWED_HOSTS` وCORS صريحان
- PostgreSQL و Redis على شبكة خاصة فقط
- Nginx كـ Reverse Proxy مع TLS
- تخزين دائم لقاعدة البيانات
- فحوصات الصحة مفعّلة

## العملية المقصودة

1. بناء حزم الويب/الجوال/الخادم.
2. تشغيل هجرات قاعدة البيانات.
3. تجميع الملفات الثابتة.
4. تشغيل Django عبر Gunicorn/Uvicorn.
5. تشغيل Celery worker وbeat.
6. الخدمة عبر Nginx.

## الذكاء الاصطناعي

تكاملات AI الخارجية تبقى معطّلة حتى يتم تفعيلها واعتمادها بشكل صريح. لا ترسل بيانات العملاء الحساسة لمزوّدين خارجيين افتراضياً.
